# Set up pstack-codex

With the local marketplace configured, run `codex plugin add pstack-codex@pstack-codex`. In the skill picker, choose `pstack-codex:jeff-mode`. State the task and what a successful result looks like.

Use `pstack-codex:setup-pstack` to inspect the available role and model choices. See [the main workflow](02-jeff-mode.md).
