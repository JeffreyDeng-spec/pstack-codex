### Worktree cleanup

Inventory the requested repo’s worktrees, branches, open PRs and local changes. Use the active host’s registered worktrees and chat attachments to determine ownership. The bundled Git audit is advisory. An unknown owner or active checkout stays in place until its status is resolved.

Use the host archive flow for a managed worktree selected for retirement. Keep the registered path fixed when the project requires it. For ordinary Git worktrees follow the repository’s cleanup process and the user’s scope. Confirm the selected worktree’s resulting status and report recoverability. Treat simulator and cache cleanup as separate tasks when requested.
